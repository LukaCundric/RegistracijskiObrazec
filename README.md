# FirstForm – Registracijski obrazec

## O projektu

To je preprosta mobilna aplikacija, izdelana v programu Android Studio z uporabo programskega jezika Java in XML.

Aplikacija omogoča uporabniku, da izpolni registracijski obrazec in si ogleda povzetek vnesenih podatkov.

## Funkcionalnosti

- ScrollView, da se po obrazcu lahko drsi tudi na manjših zaslonih
- TextView z naslovom »Registration form«
- EditText polja za Username, Full name, Country, Email, Phone number in Password
- RadioGroup z izbiro spola (Male / Female)
- CheckBox za strinjanje s pogoji uporabe
- Button »Create account«, ki prikaže AlertDialog s povzetkom vnesenih podatkov

## Uporabljene tehnologije

- Java
- XML
- Android Studio
- Android SDK

## Delovanje aplikacije

Uporabnik izpolni registracijski obrazec, izbere spol in označi, ali se strinja s pogoji uporabe.

Po kliku na gumb **Create account** se odpre pogovorno okno z naslovom **Registration Details**, v katerem so prikazani vneseni podatki.

## Struktura projekta

- `MainActivity.java` – vsebuje kodo za obdelavo podatkov in klikov na gumb.
- `activity_main.xml` – vsebuje postavitev in videz registracijskega obrazca.

## Namen projekta

Projekt je nastal v okviru šolske naloge pri predmetu razvoja mobilnih aplikacij. Njegov namen je spoznavanje izdelave uporabniških vmesnikov za Android, obdelave uporabniških vnosov in prikaza podatkov.
